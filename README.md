# Auto WebP Image Manager

Obsidian 插件：粘贴/拖拽图片自动转为 WebP 保存，按笔记名自动命名，笔记重命名时图片同步重命名。

## 功能

- **自动转换**：粘贴或拖拽图片到笔记时，自动转为 WebP 格式
- **压缩质量**：默认 75%，可在设置中调节（0.1 - 1.0）
- **尺寸缩放**：超过最大宽高时自动缩小，保持宽高比（默认 1920×1080）
- **自动命名**：`笔记名-image-01.webp`、`笔记名-image-02.webp`...
- **指定文件夹**：图片统一保存到指定文件夹（默认 `图片/`）
- **同步重命名**：笔记改名时，关联图片自动改名，笔记内链接自动更新
- **链接格式**：支持 Wikilink `![[名.webp]]` 和 Markdown `![](路径/名.webp)`

## 安装

1. 确认插件文件夹位于：`<库目录>/.obsidian/plugins/auto-webp-image-manager/`
2. 打开 Obsidian → 设置 → 第三方插件
3. 关闭「安全模式」（如未关闭）
4. 在已安装插件列表中找到 **Auto WebP Image Manager**，启用

## 配置

设置 → 第三方插件 → Auto WebP Image Manager → 齿轮图标

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 图片保存文件夹 | `图片` | 相对于库根目录的路径 |
| 序号位数 | 2 | 01, 02, 03... |
| WebP 质量 | 0.75 | 0.1-1.0，越小文件越小 |
| 启用图片缩放 | 开 | 超过最大尺寸时自动缩小 |
| 最大宽度 | 1920 | 像素 |
| 最大高度 | 1080 | 像素 |
| 链接格式 | Wikilink | Wikilink 或 Markdown |
| 处理粘贴图片 | 开 | Ctrl+V 粘贴时处理 |
| 处理拖拽图片 | 开 | 拖入图片时处理 |
| 笔记重命名同步图片 | 开 | 笔记改名时图片同步改名 |

## 使用

1. 在笔记中按 Ctrl+V 粘贴截图或图片，或直接拖拽图片到编辑区
2. 图片自动保存到 `图片/笔记名-image-01.webp`
3. 笔记中自动插入图片链接
4. 修改笔记文件名时，关联的图片自动同步改名

## 命名示例

笔记名：`项目方案.md`
- 第1张图：`图片/项目方案-image-01.webp`
- 第2张图：`图片/项目方案-image-02.webp`

笔记改名为 `新版项目方案.md` 后：
- `图片/新版项目方案-image-01.webp`
- `图片/新版项目方案-image-02.webp`
- 笔记内链接自动更新

## 注意

- 如同时安装了 Image Converter 或 Custom Attachment Location，可能存在粘贴事件冲突，建议在那些插件中关闭自动粘贴处理
- 修改「处理粘贴/拖拽」开关后需重启 Obsidian 生效
- 图片质量和缩放设置仅对新粘贴/拖拽的图片生效，不会自动转换已有图片
